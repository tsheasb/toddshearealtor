# SB Residency — Brand & Voice Reference

## Identity

Todd Shea, REALTOR® (DRE #02028163), Berkshire Hathaway HomeServices
California Properties. Serves Santa Barbara, Montecito, Carpinteria, and the
Santa Ynez Valley (also works Ventura/Ojai/Goleta but FLEX MLS territory
only covers SB County — Ventura properties need public records/portal
fallback, not FLEX MLS).

Tagline, appears at the sign-off of every issue: **"Live On Vacation | The
Vibe Is Right | Made in Santa Barbara"**

## Voice

Short, confident, salty. No corporate tone. Casual but professional — like
talking to a close friend you also respect, not ultra-casual. Todd jokes
around but stays professional; match the tone of whoever he's writing to.

**Hard rule: never use em dashes or en dashes.** Standard punctuation only
(periods, commas, colons, parentheses). Real people don't type with dashes
like that. If you catch an em dash in a draft, rewrite the sentence, don't
just swap in a comma if it changes the meaning.

## Compliance

Broker attribution shortens to **"Berkshire Hathaway HomeServices"** — never
the full legal name ("...California Properties" gets dropped in body copy).

Every non-Todd listing in Window Shopping needs: agent name + office name,
MLS number, and the "not my listings" disclaimer under the section's CTA.
BHHS formal compliance review is optional per Todd's standing direction —
the safeguards above are the substitute.

## What NOT to do

- No em/en dashes, ever, anywhere in SB Residency copy.
- Don't invent stats — pull real numbers from FLEX MLS, cite the caveat if
  sample size is small (e.g., Montecito ~10 sales/month, medians swing hard).
- Don't use a third-party company's logo/trademark for "Currently Obsessed
  With" photos if it could read as an implied endorsement — Todd's own
  photo/screenshot instead.
- Don't publish sensitive personal financial/health figures even if Todd
  shares them in chat for context — build a generic version instead (see
  the Issue 02 personal dashboard mockup as the template for this pattern).
